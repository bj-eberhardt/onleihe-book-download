# Onleihe Book Saver

Ein Userscript für **Greasemonkey** und **Tampermonkey**, das die aktuell aktive Buchseite der Onleihe v3 erkennt, das darin gerenderte `<canvas>` speichert und herunterlädt. Es wechselt automatisch zur nächsten Seite, bis das Buch vollständig gesichert wurde. Mit Tools wir "Adobe PDF Reader" kann man aus den einzelnen Screenshots nun eine PDF erzeugen.

A userscript for **Greasemonkey** and **Tampermonkey** that detects the currently active PDF page in the Onleihe version 3 webversion, saves its rendered `<canvas>`, and then automatically continue to the next page until the whole book is stored on disk. You can then with tools like "Adobe Reader" create a PDF book with given screenshots.

---

## 🇩🇪 Deutsch

### Installation

1. Installiere **Greasemonkey** oder **Tampermonkey**.
2. Öffne die RAW-Version der Userscript-Datei:

```text
 https://raw.githubusercontent.com/bj-eberhardt/onleihe-book-download/master/onleihe-canvas-saver.user.js
```

3. Der Userscript-Manager sollte die Datei automatisch als Userscript erkennen.
4. Klicke auf **Installieren**.
5. Öffne anschließend ein Buch in der Onleihe (https://o3reader.onleihe.de).
6. Für bessere Qualität, scrolle in dem Menü auf "Leseeinstellungen" und vergrößere die Schrift.
7. Klicke dann auf den "Save All Canvas" Button unten rechts.

## 🇬🇧 English


### Installation

1. Install **Greasemonkey** or **Tampermonkey**.
2. Open the RAW version of the userscript:

```text
 https://raw.githubusercontent.com/bj-eberhardt/onleihe-book-download/master/onleihe-canvas-saver.user.js
```

3. Your userscript manager should automatically recognize the file.
4. Click **Install**.
5. Open the supported website, https://o3reader.onleihe.de and open a book.
6. For better quality, go to the menu and increase the font size in the reader settings.
7. Now click on the button "Save All Canvas".
